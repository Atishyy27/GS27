QUALITY OVER COUNT

Finish a sheet. Then count.

  • Questions matter. Completing a sheet matters more.
  • Pick ONE sheet and finish it (Striver A2Z / NeetCode 150 / CSES).
  • Track 4 platforms: LeetCode · CodeChef · Codeforces · AtCoder
  • Upsolve every contest problem you couldn't do. That's where rating comes from.
LIVE: OPEN SOURCE

Watch me find and solve an issue. Right now.

  • Find the org: LFX / CNCF / GSoC lists, filter by your stack
  • Find the issue: 'good first issue', recent activity, maintainer replies fast
  • Comment first, then build, then a small clean PR
  • Live demo: one real issue, start to PR
  • One merged PR in a real org beats five clone projects on a resume
LIVE: COLD MAIL

My real count: ~120 cold mails. Not 573. Still worth it.

  • Personalised beats mass. Every time.
  • The shape: who you are (1 line) → why THEM (1 line, specific) → proof (link) → one clear ask
  • Keep it under 120 words. Subject line = the ask.
  • Live demo: I'll write one in front of you with a prompt + chat
  • One named person who can say yes. Not careers@, not a form.
  • ~10 a month, not 50. No reply by day 5? It's dead. Next name, no chasing.
Earlier he quoted 573; the real number is in the 120s. Saying the correction out loud builds trust.
